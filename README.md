## 🌍 The Vision

> Some worlds are too extraordinary to be forgotten.

More than twenty years after its release, the original **Guild Wars** continues to inspire adventurers around the world.

**Guild Wars Codex** is an independent fan project dedicated to exploring, documenting, and celebrating the world of Guild Wars.

What begins as an interactive atlas is intended to grow into a comprehensive reference for everything that makes this universe remarkable.

From the streets of Ascalon to the distant lands of Cantha and Elona, every location has a story worth preserving.

**One world. Thousands of discoveries. One Codex.**

---

## 🗺️ Features

### Interactive World Atlas

Explore the world through detailed, interactive maps.

- 🏰 **Tyria** — From Ascalon to the Ring of Fire
- 🌸 **Cantha** — The ancient empire and its distant lands
- 🏜️ **Elona** — The lands of the Sunspears
- ⚔️ **Battle Isles** — The heart of competitive combat
- ❄️ **Eye of the North** — Beyond the Far Shiverpeaks

Planned atlas capabilities include:

- Interactive navigation and zoom
- Cities, outposts, missions, and explorable areas
- Location markers and contextual information
- Multilingual names and labels
- Search and filtering tools

### Multilingual Encyclopedia

Knowledge should have no language barrier.

| Language | Code | Planned support |
|---|---|---|
| 🇬🇧 English | EN | ✓ |
| 🇫🇷 Français | FR | ✓ |
| 🇩🇪 Deutsch | DE | ✓ |
| 🇪🇸 Español | ES | ✓ |

The Codex aims to document:

- Locations and explorable areas
- Missions and quests
- Dungeons and challenges
- Professions and skills
- Items and equipment
- Game mechanics and reference information

### Community Tools

Beyond the atlas, Guild Wars Codex aims to introduce additional tools and resources for players.

Possible future features include:

- Advanced search and filters
- Skill and build references
- Exploration and completion tools
- Personalized utilities
- Community-driven improvements

*Features will be introduced progressively as development continues.*

## 🛠️ Technology

Guild Wars Codex is designed to remain lightweight, fast, and accessible.

| Component | Technology |
|---|---|
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| Data | Structured JSON |
| Maps | Tiled interactive cartography |
| Version control | Git & GitHub |
| Hosting target | Cloudflare Pages |
| Map storage target | Cloudflare R2 |
| Future backend | To be determined |

The architecture is intended to evolve as the project grows, without introducing unnecessary complexity.
